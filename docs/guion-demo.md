# Guion de demostración de diez minutos

El guion prepara la defensa; no sustituye al video grabado que pide la guía.

| Tiempo | Mostrar | Explicación |
|---|---|---|
| 0:00-1:00 | Vista conceptual | Problema, alcance alrededor de La Paz y objetivo de importar y compartir GPX. |
| 1:00-2:00 | Diagramas C4 | Gateway, identidad, rutas, GIS, mensajería y registro de pruebas. |
| 2:00-3:00 | API /docs y registro | JWT, roles y separación de rutas públicas de actividades personales. |
| 3:00-4:00 | Importación GPX | Segmentos, distancia, desnivel, estado borrador y publicación. |
| 4:00-5:00 | Finalización manual | Dos llamadas cuentan una sola persona. No es evidencia GPS. |
| 5:00-6:00 | Reportes y fotos | Punto geográfico, estado sin verificar, moderación posterior y eliminación de EXIF. |
| 6:00-7:00 | Prueba de frontera 200/201 | Mostrar evidencia QA: edición directa con 200, propuesta pendiente con 201. Las visitas de prueba son sintéticas. |
| 7:00-8:00 | /audit y /proofs | SHA-256, recibo real EVM local y comparación de huellas. No afirmar que es Sepolia. |
| 8:00-9:00 | Evidencia SQA | Pruebas, cobertura medida, k6 y límites de la medición. |
| 9:00-10:00 | Matriz de cumplimiento | Sepolia, nube, evidencia académica y pasos posteriores. |

Para reproducir el recorrido principal: `npm run demo`. La ejecución crea usuarios y una ruta nuevos con datos sintéticos; no borra contenido existente.
