# Dirección visual

Una herramienta de campo para el relieve andino. El mapa ocupa dos tercios de la pantalla y la ficha de ruta el tercio restante. La acción principal es importar un GPX; completar una ruta es una acción secundaria dentro de su ficha.

- Paleta: fondo hielo #EDF3F5, papel #FFFFFF, tinta azul petróleo #183F4C, ruta azul #126C8A, curvas #BCCDD1, advertencia ámbar #A56216.
- Tipografía: Lato para títulos, controles y lectura. Cifras alineadas y unidades explícitas.
- Composición: cabecera baja, ficha izquierda, mapa continuo a la derecha. Texto alineado a la izquierda. Un solo botón principal por contexto.
- El gesto visual distintivo es el trazado atravesando curvas de nivel, con inicio circular, llegada cuadrada y flechas de sentido.

Revisión del brief: se elimina una portada comercial y cualquier llamada a prueba gratuita, porque el modelo comercial está pendiente. Las fotografías se muestran como espacios de contenido sin atribuir imágenes ficticias al lugar. El satélite y la edición manual aparecen como conceptos previstos, diferenciados del GPX disponible en el backend.
